# 🎌 Anime Recommendation System

A simple **content-based anime recommendation system** built with **Python, Pandas, and Scikit-learn**.

### How it works
Uses **TF-IDF + Cosine Similarity** to find anime with similar genres, types, and descriptions.

### Run

```bash
pip install -r requirements.txt
python recommender.py
```

### Commands

```text
recommend Naruto
search dragon
genre fantasy
quit
```

### Tech
- Python
- Pandas
- NumPy
- Scikit-learn
